# Viiden SIP-aukon rajattu uudelleentarkistus

Kohde: `audit-hardening-v1`. Tämä on datan tarkistus, ei tuottotesti eikä
käyttöönotto. Oracle-palvelinta tai oikean rahan kaupankäyntiä ei muuteta.

## Käyttäjän koneella havaitut tiedot

Käyttäjän lukukomentojen tulosteiden mukaan kummastakin kansiosta (`data` ja
`data_sip`) löytyivät kaikki 102 odotettua hintatiedostoa. Perustarkistus ei
havainnut puuttuvia/virheellisiä aikaleimoja, duplikaatteja, epäjärjestystä,
viiden minuutin ruudukon poikkeamia tai tarkistettuja OHLCV-rajojen virheitä.
Tämä ei todista datan alkuperää, corporate action -asetuksia tai hintojen
markkinaoikeellisuutta.

Elokuun 2026 vertailu saman kansion SPY-hetkiin (1638 havaintoa) löysi aukkoja
67 `data`-tiedostosta ja kahdesta `data_sip`-tiedostosta. Jälkimmäisen viisi
puuttuvaa hetkeä ovat:

| Osake | UTC | New York |
|---|---|---|
| EQIX | 2026-08-11 18:55 | 2026-08-11 14:55 |
| EQIX | 2026-08-18 18:05 | 2026-08-18 14:05 |
| EQIX | 2026-08-26 14:05 | 2026-08-26 10:05 |
| EQIX | 2026-08-28 18:05 | 2026-08-28 14:05 |
| BLK | 2026-08-13 17:20 | 2026-08-13 13:20 |

Nämä ovat käyttäjän paikallisista tiedostoista raportoituja havaintoja.
Assistentin ympäristöön koko 102 tiedoston aineistoa ei ole toimitettu.
SPY:n kattavuutta ei ole tässä vahvistettu erillisellä pörssikalenterilla.
GitHubin tarkistetut `download_data.py`, `research_v62_download_missing.py` ja
`research_v64_download_holdout.py` käyttävät IEX-syötettä. `data_sip`-kansion
alkuperäistä latausohjelmaa ei löytynyt tarkistetuista repo-tiedostoista;
kansion nimi ei yksin todista syötettä tai hintojen oikaisuasetusta.

## Uusi työkalu

`tools/probe_missing_bars.py` tekee vain historiallisten hintojen GET-hakuja
osoitteesta `https://data.alpaca.markets/v2/stocks/{symbol}/bars`. Se ei luo
kaupankäyntiasiakasta eikä kutsu tili-, toimeksianto- tai peruutusrajapintoja.

- Viisi kiinteää aikaikkunaa: puuttuva hetki sekä kaksi viiden minuutin
  kynttilää sen molemmin puolin. Rajat ovat API:ssa inklusiiviset.
- Pyyntöparametrit kirjataan: `feed=sip`, `adjustment=raw`, `asof=2026-08-31`,
  `timeframe=5Min`, `sort=asc`. Tämä on eksplisiittinen vertailuhaku, ei väite
  vanhan aineiston alkuperäisistä latausasetuksista.
- Sivutus käsitellään; toistuva sivutustunnus tai odottamattoman pitkä vastaus
  pysäyttää kyseisen tarkistuksen. Ei automaattisia uudelleenyrityksiä tai
  HTTP-uudelleenohjauksia; yhteys-/lukuaikaraja on 5/20 sekuntia.
- Avaimet luetaan vain käyttäjän valitsemasta paikallisesta tiedostosta
  `python-dotenv==1.2.1`:llä ilman ympäristömuuttujien laajennusta tai vientiä.
  Avaimia, HTTP-otsakkeita ja poikkeusten vastaustekstejä ei tulosteta.
- Vastausrivit validoidaan samalla OHLCV-normalisoijalla kuin simulaattorissa.
  Aikaleimojen on pysyttävä pyydetyssä ikkunassa. Duplikaatit hylätään.
- Täydennysehdokas tallennetaan vain, jos välittömät viereiset kynttilät ovat
  paikallisessa aineistossa ja kaikki paikalliset ikkunan vertailurivit
  täsmäävät vastaukseen. Hintatoleranssi on absoluuttinen 0,000001 USD,
  suhteellinen toleranssi 0; volyymien pitää täsmätä täsmälleen.
- Raakavastaukset, asetukset, alkuperäisten tiedostojen SHA-256:t ja tarkistuksen
  tila tallentuvat uuteen hakemistoon. Alkuperäisiä CSV-tiedostoja ei kirjoiteta.
  Lopuksi niiden tiivisteet tarkistetaan uudelleen.
- Jo olemassa olevaa tuloshakemistoa tai alkuperäisen datahakemiston sisälle
  sijoittuvaa tuloskansiota ei hyväksytä. Jo paikallisesti löytyvää kynttilää
  ei haeta uudelleen. Ohjelma ei interpoloi, kopioi IEX-kynttilöitä SIP:n sekaan
  tai poista ongelmallisia osakkeita/päiviä.

Mahdolliset tilat: `candidate_for_review`, `absent_from_response`,
`context_mismatch`, `already_present_locally`, `request_or_validation_error`.
Ehdokas ei ole automaattisesti hyväksytty korjaus. Vastauskontekstin täsmääminen
on paikallinen tarkistus, ei todiste koko historian yhtenäisestä alkuperästä.
Tyhjä vastaus ei todista kauppojen puuttumisen syytä tai datan täydellisyyttä.

## Windows PowerShell

Suorita aiemmin luodussa erillisessä simulaatiokansiossa:

```powershell
& {
    git pull --ff-only origin audit-hardening-v1
    if ($LASTEXITCODE -ne 0) { throw 'Git update failed' }
    .\.venv\Scripts\python.exe -m pip install -r requirements-simulation.txt
    if ($LASTEXITCODE -ne 0) { throw 'Dependency installation failed' }
    .\.venv\Scripts\python.exe -X utf8 tools\probe_missing_bars.py `
        --data-dir "$env:USERPROFILE\Downloads\trade_bot_v5.2\data_sip" `
        --env-file "$env:USERPROFILE\Downloads\trade_bot_v5.2\.env" `
        --output-dir research_runs\sip-aukot-1
    if ($LASTEXITCODE -ne 0) { throw 'Probe incomplete; inspect the report or error above' }
}
```

Valittu `.env` vastaa GitHubin vanhan `download_data.py`:n käyttämää polkua.
Jos käyttäjän paikalliset avaimet ovat toisessa tiedostossa, annetaan sen polku
`--env-file`-argumenttina. Tiedoston puuttuminen ei aiheuta automaattista
avainten etsintää. Avaimia ei pidä kopioida keskusteluun.

Työkalu tarvitsee verkkoyhteyden hintahakuun; aiempi toimintasimulaatio pysyy
offline-ajona. 401/403 tallennetaan virheenä, eikä puuttuvia käyttöoikeuksia
kierretä toisella syötteellä. Mitään maksullista palvelua ei tilata.

Tulokset: `research_runs/sip-aukot-1/report.json`, viiden ikkunan vastaustiedostot
sekä mahdolliset `*_candidate_ONLY.csv`-tiedostot. Seuraava päätös perustuu
raporttiin; tuottoa ei lasketa eikä strategian parametreja muuteta tässä vaiheessa.

## Testit ja rajat

Kahdeksan uutta offline-testiä kattavat kontekstin täsmäyksen/hylkäyksen,
puuttuvan vastauksen, duplikaatit, väärän aikaikkunan, alkuperäisten säilymisen,
ylikirjoituseston, jo löytyvän kynttilän ohituksen, virhetekstien salaamisen,
GET-rajauksen/sivutuksen ja avaintiedoston laajennusten eston. Yhteensä 108 testiä.

Paikalliset testitulokset: [pandas 2.2.3](audit_evidence/2026-10-26-gap-probe/pandas-2.2.3/test_results.json)
ja [pandas 3.0.0](audit_evidence/2026-10-26-gap-probe/pandas-3.0.0/test_results.json).
GitHub Actions ajaa lisäksi Windows/Linux-matriisin ja aiemman synteettisen
simulaation. Toteutunut CI-tulos tarkistetaan kyseisen commitin Actions-ajosta.

Assistentti ei ole käyttänyt käyttäjän avaimia tai tehnyt tämän työkalun
reaalisia Alpaca-hakuja. Testeissä HTTP-vastaukset korvataan valevastauksilla ja
ulospäin suuntautuvat socket-yhteydet on estetty. Oikean historiallisen
simulaation käynnistys, elokuun kalenterin varmennus ja käyttöönoton aiemmat
EOD-/välittäjäesteet ovat yhä erillisiä tehtäviä.

## Lähteet

Alpaca kertoo, ettei kynttilää välttämättä muodosteta, jos aikavälillä ei ole
hintojen muodostamiseen kelpaavia kauppoja. Yli minuutin kynttilät muodostetaan
minuuttikynttilöistä. Tämä on mahdollinen selitys, ei diagnoosi näille aukoille.

- https://docs.alpaca.markets/us/docs/market-data-faq
- https://docs.alpaca.markets/us/reference/stockbars
- https://docs.alpaca.markets/us/reference/stockbarsingle-1
